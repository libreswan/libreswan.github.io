Where and how to do work:


Video Calls?

We'd like each of you and your Mentor to schedule a one 1-1 Google
Meetup (or your poison of choice) each week.  And we encourage other
add-hoc sessions - a face to face discussion has much higher bandwith.


IRC?

If not already, can you find a way to be on IRC.


Where?

Our first preference is on GitHub with a public repository and pull
requests pull-request.

If this is a problem we can also set up private repository.  As a side
note, Google (I'm told) likes to see the final deliverable presented
as a branch (while, IMNSHO, that is not the best way to work with old
code, It's Google that is running things).


Testing?

To help with testing, we can set up dedicated (remote) hardware so
tests can be run overnight if needed.  We don't want you to leaving a
noisy hot computer running overnight cooking your workspace.
