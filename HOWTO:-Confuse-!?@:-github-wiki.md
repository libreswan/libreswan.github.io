Some notes on using github's wiki

It allows both markdown (.md) and asciidoc (.asciidoc).

To get a Table-of-Contents, asciidoc is needed.
To get the _Sidebar including turn-downs, asciidoc is need.

Markdown and asciidoc can reference each other.  Just put ./ at the
start of the link.

It's still not clear how github handles special characters.  With ./
colons are allowed, what of others?

It's still not clear if directories are possible for markdown (it does
work with images).
